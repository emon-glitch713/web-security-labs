## Unprotected Admin Functionality Lab

### Steps:

1. I accessed `/robots.txt` by adding it to the URL.
2. Found a hidden path: `/administrator-panel`
3. Navigated directly to that URL.
4. Admin panel loaded without login.

### Vulnerability:

No authentication or access control on admin panel.

### Impact:

Unauthorized users can access sensitive admin functionality.
